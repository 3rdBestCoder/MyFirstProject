# MyFirstProject
Coffee Shop Lab
This program will ask you if you are a member, then take your order, and lastly calculate your total.
## How to Run
1. Open the program in your IDE.
2. Type Y if you are a member and N if you are not
3. Choose which drink you want
4. View your final price
   Example output:
Drink: Latte
Base Price: $4.5
Discount: 10.0 %
Final Price: $4.05
